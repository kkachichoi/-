# 2분할 카페 릴스 스타일 분석 & 따라 만들기

분석 대상: `@rikabypaprika` 릴스 (화면 녹화본 15.4초, 릴스 본편 약 12초)
분석 방법: ffmpeg로 프레임 추출, 장면 전환(컷) 자동 감지, 오디오 레벨 측정

## 1. 한 줄 요약

> **화면을 위아래로 나눠 "음식 클로즈업 + 매장/만드는 과정"을 동시에 보여주고, 음악 박자에 맞춰 두 화면을 같이 바꾸다가, 마지막에 매장 전체 화면 + 손글씨 로고로 끝내는** 약 12초짜리 브랜드 무드 영상.

### 컷 타임라인 (자동 감지 결과)
위 패널과 아래 패널이 **항상 같은 순간에 동시에** 바뀝니다.

| 시간 | 길이 | 위 패널 | 아래 패널 |
|---|---|---|---|
| 0.0–1.4초 | 1.37초 | 토마토 오픈 샌드위치 클로즈업 | 창가 쪽 매장 전경, 일하는 직원 |
| 1.4–2.7초 | 1.35초 | 모자 쓴 직원들이 일하는 카운터 | 장갑 낀 손으로 빵 써는 모습 |
| 2.7–3.8초 | 1.07초 | **전체 화면** 슬라이서 익스트림 클로즈업 (분할 해제) | |
| 3.8–5.2초 | 1.37초 | 연어·크림치즈 베이글 접시 | 매장 인테리어 (조명, 벽 장식, 빵 진열) |
| 5.2–6.5초 | 1.37초 | 어두운 조명 속 빵 덩어리 | 에스프레소 추출 |
| 6.5–8.0초 | 1.5초 | 포장하는 직원 손 | 토치로 빵 위 치즈 굽기(불꽃) |
| 8.0–9.4초 | 1.33초 | 05:00 타이머 | 수프 위에 허브 올리기 |
| 9.4–11.8초 | 약 2.4초 | **전체 화면** 매장 와이드샷 + 로고 | |

**핵심 숫자: 컷 하나 약 1.37초**, 처음부터 끝까지 거의 일정합니다. 음악 박자에 맞춘 편집으로 보이며, 1.37초는 약 88BPM 노래의 2박자에 해당합니다.

**변주 포인트:** 3번째 컷에서 한 번 **분할을 풀고 전체 화면 클로즈업**을 넣어 리듬을 깨줍니다. 계속 2분할만 나오면 단조로워지는 걸 막는 장치예요.

### 위/아래 짝 짓는 규칙
매번 **"결과물(음식) + 과정 또는 공간"** 을 한 쌍으로 묶습니다.
- 위: 완성된 음식, 디테일 (정적, 예쁜 것)
- 아래: 손 동작, 기계, 불꽃, 매장 분위기 (움직임 있는 것)

→ 한 화면은 차분하고 한 화면은 움직이니 정보량이 2배인데도 정신없지 않습니다.

## 3. 비주얼 스타일

| 요소 | 특징 | 따라하는 법 |
|---|---|---|
| 색감 | 따뜻한 노랑·주황 톤, 채도 살짝 낮춤, 블랙이 약간 떠 있는 필름 느낌 | 화이트밸런스 따뜻하게, 채도 -10, 대비 살짝 +, 그레인 약간 |
| 포인트 컬러 | 빨강(파프리카 로고, 그릇 테두리, 슬라이서, 소품)과 초록 타일 | 브랜드 색 1~2개를 소품/의상에 반복 배치 |
| 초점 | 얕은 심도(배경 흐림) 클로즈업 많음 | 아이폰 **시네마틱 모드** 또는 인물 모드 영상, 렌즈 가까이 |
| 카메라 | 거의 고정 또는 아주 느린 움직임, 흔들림 없음 | 삼각대/짐벌, 손으로 찍으면 팔꿈치 몸에 붙이기 |
| 조명 | 자연광(큰 창) + 따뜻한 펜던트 조명 | 오후 창가 시간대에 촬영 |
| 인물 | 얼굴보다 **손, 뒷모습, 옆모습**. 유니폼(모자, 앞치마)으로 통일감 | 손 클로즈업 위주로 찍기 |

## 4. 촬영 체크리스트 (샷 리스트)

이 스타일은 **최소 12~16개 짧은 클립**이 필요합니다. 각 클립은 3~5초씩 넉넉히 찍으세요 (편집 때 1.4초만 사용).

**음식 결과물 (위 패널용, 6개 이상)**
- [ ] 대표 메뉴 접시 45도 클로즈업
- [ ] 단면, 토핑 디테일 초근접
- [ ] 음료, 커피 잔
- [ ] 빵/디저트 진열

**과정 (아래 패널용, 6개 이상)**
- [ ] 칼이나 슬라이서로 써는 손
- [ ] **전체 화면용 익스트림 클로즈업 1개** (기계, 질감 등 화면을 꽉 채우는 것)
- [ ] 에스프레소 추출
- [ ] 토치, 불꽃, 김 나는 장면 (임팩트 컷, 중반 이후 배치)
- [ ] 가니시 올리는 손
- [ ] 포장하는 손

**공간 (아래 패널 + 엔딩용)**
- [ ] 매장 전경 와이드 (**엔딩용, 로고 넣을 빈 공간이 가운데 있게**)
- [ ] 인테리어 디테일 (조명, 벽, 소품)
- [ ] 일하는 직원 뒷모습

**촬영 팁**
- 가로로 찍어도 됩니다. 패널 하나가 가로형이라 가로 영상을 잘라 쓰기 좋아요.
- 4K 30fps 또는 60fps로 찍어두면 확대·슬로모션 여유가 생깁니다.
- 노출을 고정(AE/AF 잠금)해서 깜빡임 방지.

## 5. 편집 방법

### A. 이 저장소의 스크립트로 자동 편집 (ffmpeg)

클립을 (위, 아래) 짝으로 순서대로 넣으면 2분할, 박자 컷, 색보정, 엔딩 로고까지 한 번에 만들어줍니다.

```bash
./make_split_reel.sh \
  -o my_reel.mp4 \
  -c 1.37 \
  -e store_wide.mp4 -t "MyCafe" -s "by Brand" -f handwriting.ttf \
  -m music.mp3 \
  toast.mp4 window.mp4 \
  barista.mp4 slicing.mp4@2.5 \
  slicer_closeup.mp4 FULL \
  bagel.mp4 interior.mp4 \
  bread.mp4 espresso.mp4 \
  packing.mp4 torch.mp4 \
  timer.mp4 soup.mp4
```

- `파일@초`: 그 클립의 몇 초 지점부터 쓸지 (예: `slicing.mp4@2.5`)
- `파일 FULL`: 아래 자리에 `FULL`을 쓰면 그 컷만 분할 없이 전체 화면 (원본의 슬라이서 컷처럼)
- `-c`: 컷 길이. 음악 BPM으로 계산하면 `120 ÷ BPM` (2박자 기준). 예: 88BPM → 1.37, 100BPM → 1.2
- `-l logo.png`: 로고 이미지가 있으면 `-t` 대신 사용 (배경 투명 PNG)
- `-f`: 손글씨 폰트 파일. 원본 느낌을 원하면 둥근 손글씨체 추천 (예: 눈누 사이트의 무료 손글씨 폰트)
- `-g none`: 색보정 끄기
- 결과: 1080×1920, 30fps, H.264

필요한 것: `ffmpeg` (맥: `brew install ffmpeg`)

### B. 캡컷(CapCut)으로 직접 편집

1. 새 프로젝트, 비율 **9:16**
2. 메인 트랙에 **위 패널 클립들**을 1.37초씩 잘라 순서대로 배치
3. **오버레이**로 아래 패널 클립들을 같은 길이로 맞춰 배치
4. 각 클립 크기 조절: 메인은 화면 위쪽 절반, 오버레이는 아래쪽 절반 (가로 꽉 차게)
5. 음악 넣고 **비트 자동 표시(Beat)** 켠 뒤 컷 경계를 박자에 맞춤
6. 3번째 컷쯤 한 번은 오버레이 없이 전체 화면 클로즈업
7. 마지막 2.5초: 오버레이 없이 매장 와이드 전체 화면 + 텍스트(손글씨체, 흰색) 페이드인
8. 조정: 온도 +15, 채도 -10, 대비 +5, 그레인 약간 (또는 따뜻한 필름 필터)

## 6. 원본에서 배울 포인트 정리

1. **자막 없이 화면만으로** 브랜드 분위기 전달 → 소리 꺼놓고 봐도 됨
2. **첫 컷부터 가장 맛있어 보이는 음식** (토마토 샌드위치) → 스크롤 멈추게 하기
3. **중간에 한 번 전체 화면 컷**으로 2분할 리듬에 변화 주기
4. **불꽃·타이머 같은 "움직임 있는 순간"을 중반에** 배치해 지루함 방지
5. **엔딩은 길게 (2.5초) + 로고만** → 브랜드 각인, 자연스러운 반복 재생
6. 전체 **12초 내외**로 짧게 → 끝까지 보는 비율(완주율) 높이기
