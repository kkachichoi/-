# 까치카페 블로그 다듬기 안내 (PRJ-19)

네이버 블로그 PC 화면 기준입니다. 네이버가 메뉴 이름을 가끔 바꿔서, 글자가 조금 다를 수 있어요.
모두 **내 블로그 → 오른쪽 위 '관리'** 에서 시작합니다.

---

## 1. 블로그 이름·별명·소개글 (5분)

**관리 → 기본 설정 → 블로그 정보**

| 칸 | 넣을 내용 |
|---|---|
| 블로그명 | `광명 하안동 까치카페 \| 조각가의 커피와 빵` |
| 별명 | `까치카페 사장` |
| 소개글 | 아래 글 그대로 붙여 넣기 |
| 블로그 프로필 이미지 | 까치 로고 (`shorts-project/my-photos/11_까치_로고.png`) |

소개글:

```
광명 하안동에서 13년째 커피를 내리는 까치카페입니다.
미술대학에서 조각을 공부한 사장이 매일 아침 베이글과 스콘을 굽고 제철 라떼를 만듭니다.
📍오리로619번길 32 ⏰평일 10:30~18:00 / 주말 10:30~21:00 · 연중무휴
💬미리 주문: 카카오톡 '까치카페'
```

맨 아래 **확인**을 누르면 저장돼요.

## 2. 맨 위 배너 바꾸기 (5분)

배너 파일: `blog/design/banner/` 안의 **A_이름판_사진3칸.jpg** 또는 **B_카운터_사진.jpg** (가로 966 × 세로 300)

**관리 → 꾸미기 설정 → 세부 디자인 설정 → 타이틀**

1. 디자인에서 **직접등록**을 고릅니다.
2. **파일 등록**으로 배너 파일을 올립니다.
3. 영역 높이를 **300**에 맞춥니다.
4. 배너 안에 블로그 이름이 이미 들어 있으니, **블로그 제목 글자 표시는 끕니다** (글자가 두 번 나오지 않게).
5. 오른쪽 아래 **적용**을 누릅니다.

## 3. 카테고리 정리 (10분)

**관리 → 메뉴·글·동영상 관리 → 메뉴 관리 → 블로그**

새 순서 (위에서부터):

1. 까치카페 메뉴: 지금 '카페를 운영하고 있습니다.'의 **이름을 바꿔서** 씁니다
2. 까치카페 소식: **카테고리 추가**
3. 조각가의 작업실: **카테고리 추가**
4. 카페 창업·운영 이야기: **카테고리 추가**
5. 매주 토요일 아이랑 카페투어: 그대로
6. 사장의 생각: '성공을 위한 마인드셋'의 이름을 바꿉니다 *(사장님이 합쳐도 된다고 하시면)*

카테고리는 마우스로 끌어서 순서를 바꿀 수 있어요. 다 했으면 **확인**을 누르세요.

창업 글 옮기기: **관리 → 메뉴·글·동영상 관리 → 글 관리 → 글 배치**에서 창업 글 4개(아래)에 체크하고 **카테고리 변경 → 카페 창업·운영 이야기**를 고릅니다.

- 카페창업 준비, 망하지 않으려면 꼭 알아야 할 5가지
- 12년 동안 카페를 운영하며 깨달은, 망하지 않는 창업 가이드
- 카페창업, 오래 살아남는 카페를 위한 현실적인 창업 이야기
- 6월 커피 교육안내 → 이건 **까치카페 소식**으로

글은 지우지 않고 자리만 옮깁니다.

## 4. 다 끝나면

채팅에 "블로그 정리 끝"이라고 해 주세요. 비서실장이 블로그를 다시 읽어서 바뀐 게 제대로 보이는지 확인하고, 다음 글로 **"까치카페 안내"** 공지 글(주소·메뉴·미리 주문 방법)을 써서 임시저장해 둘게요.
