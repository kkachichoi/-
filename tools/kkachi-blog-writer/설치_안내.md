# 까치카페 블로그 도구 설치하기

가이드 11쪽과 같은 순서예요. PC 크롬에서 해 주세요.

1. 받은 `kkachi-blog-writer.zip`을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 합니다. 바탕화면처럼 찾기 쉬운 곳에 풀어 주세요.
2. 크롬 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 방금 푼 **kkachi-blog-writer 폴더**를 고릅니다. (ZIP 파일이 아니라 폴더예요)
5. 크롬 위쪽 퍼즐 아이콘 → **까치카페 블로그 도구** 옆 핀을 눌러 고정합니다.
6. 초록색 **B** 아이콘을 누르면 오른쪽에 도구가 열립니다.

폴더는 지우거나 옮기지 마세요. 크롬이 그 폴더에서 도구를 읽어요.

## 쓰는 순서

1. **주제**: 글 목적을 고르고, 오늘 쓸 주제와 직접 확인한 사실을 적어요. 가게 기본 정보(주소·영업시간·재료 등)는 미리 들어 있어요.
2. **사진**: 넣을 사진을 고르고 순서를 정해요. 건너뛰어도 돼요.
3. **원고**: 다른 탭에서 gemini.google.com에 로그인한 뒤 **Gemini 연결** → **원고 만들기**. 받은 원고를 읽고 **원고 저장**.
   - 연결이 안 되면 **부탁문 보기 → 부탁문 복사**로 Gemini에 직접 붙여 넣고, 받은 글을 제목·본문 칸에 붙이세요.
4. **네이버**: **네이버 글쓰기 열기** → 제목 복사 → 본문 복사 → [사진1] 자리에 같은 번호 사진 넣기.
5. **발행 확인**: 체크리스트를 보고, 발행은 네이버에서 직접 눌러요.

## 고친 파일을 받았을 때 (가이드 16쪽)

새 ZIP을 다른 곳에 풀고, 안의 파일들을 처음 등록한 kkachi-blog-writer 폴더에 덮어쓴 뒤, `chrome://extensions`에서 도구 카드의 둥근 화살표(새로고침)를 누르세요.

## 알아 둘 것

- Gemini 화면 구조가 바뀌면 연결이 안 될 수 있어요. 그때는 부탁문 복사 방식으로 쓰고, 비서실장에게 "Gemini 연결이 안 돼"라고 알려 주세요.
- 이 도구는 네이버 발행 버튼을 대신 누르지 않아요.
- 적은 내용과 원고는 이 크롬에만 저장돼요.
