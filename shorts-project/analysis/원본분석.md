# 원본 분석: print_bakery 릴스 (작가 문영서 인터뷰)

- 길이: 약 78초, 세로 1080×1920
- 형식: 작가 본인 내레이션(인터뷰) + 작업 과정/영감 장면 + 잔잔한 배경음악
- 자막: 화면 가운데보다 약간 아래, 흰색 작은 글씨, 한 줄, 말하는 속도에 맞춰 짧게 끊어서 표시
- 효과: 대부분 그냥 컷으로 넘어감(화려한 전환 없음). 3분할 콜라주 한 번, 끝에 로고 글자 한 번

## 이 영상이 잘 되는 이유 (우리 대본에 살릴 뼈대)

1. **인사 + 한 줄 소개**로 바로 시작 (누구인지, 무엇을 하는지 5초 안에)
2. **"왜"를 먼저** 말하고, 그다음에 **"어떻게"** 만드는지 보여 줌
3. 중간에 **일상 속 작은 순간**(영감)으로 공감을 만듦
4. **요즘 근황** → **감사와 다음 약속**으로 따뜻하게 끝냄
5. 말과 화면이 같은 내용을 보여 줌 (그림자 이야기 → 그림자 화면)
